## الإعدادات
- الاسم الرسمي: محاسبة بقالتي
- المالك الفكري: إسماعيل أبكر
- صفحة الملكية وبيانات الإصدار: «حول التطبيق»
- applicationId: `com.esmaeil.groceryapp`
- versionName: `2.1.0` — versionCode: `201`
- minSdk: 23 — compileSdk/targetSdk: 35
- قاعدة Room محلية، مخططها الإصدار 9، مع ترحيلات صريحة غير هدّامة حتى 8→9.
- واجهة Android الأصلية تحفظ الأصناف والشركاء والمخزون الافتتاحي والفواتير والقيود والحركات في Room.
- البيع النقدي والآجل ذري ويمنع إعادة الاعتماد بمفتاح فريد؛ فواتير البيع قابلة للبحث والعرض ولا توجد عملية حذف لها.
- التهيئة الأولى تنشئ مالكًا بـ PIN مشتق ومملّح ورمز استعادة أحادي الاستخدام. صلاحيات الخدمات تُفحص عند العمليات، والجلسة تنتهي بعد الخمول، وأضيف خيار دخول بيومتري مربوطًا بـ Android Keystore. لم يُتحقق من ذلك على جهاز/محاكي.
- أضيفت شاشة عمليات Room للشراء متعدد الأصناف، والقبض والسداد، والمصروفات، والمسحوبات، والمرتجعات؛ تستخدم هذه الخدمات معاملات Room وفحوص الصلاحية. يلزم نجاح اختبارات instrumentation قبل اعتبارها متحققة على جهاز.
- يمكن إنشاء ملف Room مستقل مشفر بكلمة مرور (AES-GCM) إلى مجلد مستندات التطبيق المحلي، ومعاينته واستعادته بعد فحص مؤقت للسلامة والعلاقات والأرصدة. تحتفظ الاستعادة بالقاعدة السابقة ولا تعتمد النسخة قبل موافقة صريحة. اختبار هذه الدورة مضاف لكنه لم يُنفذ بعد على Android.
- لا يوجد مزود أو رفع سحابي. لا يرسل التطبيق النسخ أو البيانات المالية إلى أي خدمة.
- ملف HTML أصل منفصل ما زال يحفظ في `localStorage` ولا يحمله التطبيق. صدّر منه JSON ثم استورده من التطبيق؛ تُحفظ البيانات كأرشيف قابل للتصدير لاحقًا ولا تتحول تلقائيًا إلى مخزون أو قيود تشغيلية.

## البناء
يشمل المشروع GitHub Actions في `.github/workflows/build-apk.yml` لتثبيت JDK 17 وAndroid SDK
Platform 35 وBuild Tools 35.0.0، ثم تشغيل فحوص Gradle واختبار Room على محاكي وبناء APK تجريبي
Debug ورفعه كـ artifact لمدة 14 يومًا. استخدم Gradle Wrapper 8.9 المرفق؛ الناتج ليس إصدارًا تجاريًا
موقّعًا بمفتاح خاص.

## حدود التحقق والاستخدام
يتطلب البناء المحلي Android SDK Platform 35 وBuild Tools 35.0.0 وJDK متوافقًا مع Gradle 8.9.
نجح محليًا `./gradlew --no-daemon check assembleDebug assembleDebugAndroidTest` باستخدام JDK 21 وAndroid SDK 35، وشمل lint واختبارات الوحدة وتجميع APK التطبيق والاختبارات. اختبار Room على المحاكي لم يبدأ بسبب توقف Package Manager في محاكي Codespaces؛ يجري تشغيله عبر GitHub Actions بعد رفع commit الفرع. نجاح تجميع APK لا يثبت نجاح اختبارات Room.
الشراء والتحصيل والمصروفات والمسحوبات والمرتجعات أصبحت موصولة بواجهات، لكن لم تُختبر دورة إدخالها على Android بعد. لا توجد مزامنة سحابية. لا يمكن اعتبار التطبيق نظامًا محاسبيًا مكتملًا قبل نجاح اختبارات Room ومعالجة تشفير القاعدة.
بيانات HTML المستوردة مؤرشفة فقط، وتحتاج مراجعة وتحويلًا محاسبيًا منفصلًا قبل اعتمادها تشغيليًا.
