# محاسبة بقالتي 2.0.0 — مشروع Android

> **تنبيه:** راجع [تقرير الفحص الهندسي](./ENGINEERING_AUDIT_AR.md). المشروع غير مكتمل محاسبيًا، ولا تستخدمه كسجل مالي وحيد. البيع وتسجيل الدخول غير مهيأين عمدًا بدل إظهار نجاح أو أمان غير حقيقي.

هذه حزمة مصدر Android وليست APK. يفتح التطبيق حاليًا شاشة Java أصلية؛ ملف `app/src/main/assets/index.html` واجهة HTML منفصلة غير موصولة بالشاشة الرئيسية. بيانات HTML مخزنة في `localStorage` وليست في Room، لذا لا تعتبر النسخة الاحتياطية الموجودة بها نسخة لقاعدة Room.

## الإعدادات
- الاسم: محاسبة بقالتي
- applicationId: `com.esmaeil.groceryapp`
- versionName: `2.0.0` — versionCode: `200`
- minSdk: 23 — compileSdk/targetSdk: 35
- قاعدة Room محلية، لكن لا توجد بعد عمليات مبيعات أو إدخال متصلة بها.
- واجهة HTML المخزنة كأصل تستخدم LocalStorage مستقلًا عن Room.

## البناء
يشمل المشروع GitHub Actions في `.github/workflows/build-apk.yml` لبناء APK تجريبي Debug ورفعه كـ artifact. الناتج ليس إصدارًا تجاريًا موقّعًا بمفتاح خاص.

## ما لم يتم التحقق منه بعد
يتطلب بناء APK تثبيت Android SDK Platform 35 وBuild Tools 35.0.0. تمت إضافة Gradle Wrapper 8.9، لكن تعذر تشغيل الاختبارات والبناء هنا لغياب Android SDK. لم يُختبر التطبيق على هاتف Android. لا تعتمد على البرنامج كسجل وحيد قبل اكتمال النظام والاختبارات والاحتفاظ بنسخ احتياطية.
